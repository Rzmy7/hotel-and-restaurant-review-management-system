

<h1>🧠 Embedding Service</h1>

<p>
This service provides <strong>semantic embeddings and vector search</strong> for hotel reviews.
It is built with FastAPI, ChromaDB, and Docker, and supports both
<strong>cloud-based</strong> and <strong>locally hosted</strong> embedding models.
</p>

<hr>

<h2>📦 Features</h2>
<ul>
  <li>Single and batch review embedding</li>
  <li>Semantic search with hotel-level filtering</li>
  <li>Dockerized for easy deployment</li>
  <li>Supports cloud (Gemini) and local (MiniLM) embeddings</li>
  <li>Designed for low-resource VPS environments</li>
</ul>

<hr>

<h2>🌐 API Overview</h2>
<ul>
  <li><strong>POST /embed</strong> – Embed a single review</li>
  <li><strong>POST /embed/batch</strong> – Embed multiple reviews</li>
  <li><strong>POST /search</strong> – Semantic search filtered by hotel</li>
</ul>

<hr>

<h2>🔁 Embedding Modes</h2>

<p>
You must choose <strong>one embedding mode</strong> at a time.
The rest of the system (API, search, database) remains unchanged.
</p>

<hr>

<h2>☁️ Mode A – Google Gemini Embeddings</h2>

<p><strong>Recommended when:</strong></p>
<ul>
  <li>VPS has low RAM (≈ 1 GB)</li>
  <li>Internet access is available</li>
  <li>External API usage is acceptable</li>
</ul>

<h3>Build Docker Image</h3>
<pre>
docker build -t embedding-service .
</pre>

<h3>Run Container (Gemini Mode)</h3>
<pre>
docker run -d \
  -p 8001:8000 \
  --env-file .env \
  -v chroma_data:/data/chroma \
  --name embedding_service \
  embedding-service
</pre>

<div class="note">
<strong>Note:</strong> The Gemini free tier has rate limits.
Batch embedding with throttling is recommended.
</div>

<hr>

<h2>🖥️ Mode B – Local Embedding Model (MiniLM)</h2>

<p><strong>Recommended when:</strong></p>
<ul>
  <li>No API limits are desired</li>
  <li>Offline operation is required</li>
  <li>VPS has at least 2 GB RAM</li>
</ul>

<h3>Build Docker Image</h3>
<pre>
docker build --no-cache -t embedding-service .
</pre>

<h3>Run Container (Local Mode)</h3>
<pre>
docker run -d \
  -p 8001:8000 \
  -v chroma_data:/data/chroma \
  --name embedding_service \
  embedding-service
</pre>

<div class="note">
<strong>First startup:</strong> The local model is downloaded on first run.
This may take 30–90 seconds.
</div>

<hr>

<h2>⚠️ Switching Between Embedding Modes</h2>

<div class="important">
<strong>Important:</strong> Embeddings generated by different models are NOT compatible.
You must delete the vector database when switching modes.
</div>

<h3>Delete Existing Embeddings</h3>
<pre>
docker volume rm chroma_data
</pre>

<p>
After deleting the volume, restart the container and re-embed all reviews.
</p>

<h2>🧾 Design Summary</h2>

<p>
The embedding service supports both cloud-based and locally hosted embedding models,
allowing flexible trade-offs between memory usage, API dependency, and operational cost.
The system is optimized for low-resource deployment while maintaining semantic accuracy.
</p>
