# 📺 User Insight Dashboard

The **User Frontend** is a modern, high-performance dashboard designed for hospitality managers to visualize and analyze review data. Built with **React 19**, **Vite**, and **TypeScript**, it offers a fluid, responsive experience for data-driven decision making.

## ✨ Key Features

*   **📊 Performance Overview**: High-level charts showing sentiment trends and source comparisons using **Recharts**.
*   **📑 Detailed Review Management**: Filterable list of customer reviews with sentiment highlighting.
*   **🔍 AI-Powered Summaries**: Quick-read summaries of review clusters generated by the backend AI.
*   **⚡ Type-Safe Data Flow**: Comprehensive TypeScript definitions ensuring robust API communication.
*   **🎨 Premium UI/UX**: Styled with **TailwindCSS** for a modern, enterprise-grade aesthetic.

---

## 🏗️ Technical Architecture

*   **Core**: React 19 + TypeScript
*   **Build System**: Vite
*   **State Management**: Zustand
*   **Styling**: TailwindCSS & Lucide React
*   **Charts**: Recharts
*   **Navigation**: React Router 7

---

## 🔧 Getting Started

### 📋 Prerequisites
*   **Node.js 18+**
*   **npm** or **yarn**

### 🚀 Installation & Setup

1.  **Navigate to frontend**:
    ```bash
    cd frontend
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Configure Environment**:
    The frontend communicates with the backend at `http://localhost:8000`. Ensure the backend is running.

4.  **Launch Development Server**:
    ```bash
    npm run dev
    ```
    Access the dashboard at: `http://localhost:5173`
